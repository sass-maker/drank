# DRank changelog

Verified milestones for the browser-local Domain Rating tracker.

## July 13, 2026 — Evidence-bounded DR Advisor

DRank added an explicit explanation action grounded only in the selected domain's observed rating and bounded trend context. Advice remains optional and browser-local.

## July 2, 2026 — Static application resilience

The Next.js application gained route and global error boundaries, and unused Web Vitals code was removed.

## Weekly dataset refresh

The shared public Domain Rating dataset is refreshed by a scheduled GitHub workflow. Personal lists and history are not part of that shared pipeline.
